Abstract

Physiotherapy clinics manage a large number of appointments, patient records and service requests on a daily basis. Manual or semi-manual processes often lead to overbooking, time conflicts, missing patient information and poor communication with patients. To address these challenges, Physio Care Center is implemented as a web-based application using PHP and MySQL, providing online appointment booking, service listing, contact management and an administrator panel to manage appointments and clinic services.

The system allows patients to view clinic information, browse physiotherapy services, select preferred dates and time slots, and submit appointment requests. The application enforces business rules such as clinic timings, Sunday closure and a maximum of three bookings per slot, thereby reducing scheduling conflicts. The admin module enables clinic staff to log in, view and update appointments, manage available services and monitor contact enquiries. This report describes the complete Software Development Life Cycle (SDLC) followed, system analysis, design models, implementation details, testing strategies and future enhancements.

Introduction

Healthcare and physiotherapy services are increasingly adopting digital solutions to improve accessibility and patient experience. In urban areas, patients expect convenient online access to information about doctors, services, clinic timings and appointment booking. Traditional phone-based or walk-in appointment systems are prone to errors, miscommunication and are difficult to track historically.

The Physio Care Center web application is designed as a complete front-end and back-end solution for a physiotherapy clinic. The public module includes pages such as Home, About, Services, Book Appointment and Contact. The admin module allows authenticated staff to manage appointments and services. The system is implemented using PHP on the server side, with a MySQL database for data storage and modern responsive HTML/CSS layouts to provide a professional look and feel.

Problem Definition

The main problem addressed in this project is the lack of a structured, online appointment and service management system for a physiotherapy clinic. Without a proper system:

  • Patients cannot easily know clinic timings, available services and the physiotherapist profile.
  • Appointments may be overbooked or booked on closed days such as Sunday.
  • There is no proper tracking of appointment history or patient enquiries.
  • Administrators have to manage appointments using paper or basic spreadsheets.

Therefore, there is a need for a web-based solution that automates appointment booking, enforces clinic rules, manages services and provides a simple interface for both patients and clinic staff.

Objectives of the Study

  • To design and develop a user-friendly web application for a physiotherapy clinic.
  • To provide online booking of appointments with time slot and date validation.
  • To allow dynamic management of physiotherapy services from the admin panel.
  • To provide a contact form for patients to send queries to the clinic.
  • To store and manage appointment data and contact messages using MySQL.
  • To follow a structured SDLC approach including analysis, design, implementation and testing.

System Analysis

Existing System

In a typical small physiotherapy clinic, appointment booking is performed manually via phone calls, WhatsApp messages or walk-in registration. There is no centralized system to restrict time slots, avoid overbooking, or maintain consistent patient records. Reporting and monthly statistics must be prepared manually, which is time-consuming and error-prone.

Proposed System

The proposed Physio Care Center system is a centralized web application where:

  • Patients can book appointments online using the appointment.php page.
  • Available services are fetched dynamically from the services database table.
  • Booking rules are enforced so that only valid days (non-Sundays) and available time slots are accepted.
  • Contact messages are stored using prepared statements to prevent SQL injection.
  • Admin users can manage appointments and services from the admin dashboard.

Implementation

The application is implemented using the PHP programming language with a MySQL database, deployed on a WAMP server environment. Core public modules include:

  • index.php: Landing page with hero section, service highlights, doctor profile and testimonials.
  • about.php: Describes the clinic, physiotherapist details, vision, mission and journey timeline.
  • services.php: Fetches active services from the database and displays them in a responsive grid with detail view.
  • appointment.php: Implements appointment booking with time-slot generation and validation.
  • contact.php: Allows users to send messages stored in the contact_messages table using prepared statements.

The admin module (e.g. admin/dashboard.php, admin/appointments.php, admin/services.php, admin/edit_appointment.php, etc.) is protected by a login system defined in admin/login.php and shared initialization scripts such as admin/_init.php. Admin users can view, update and delete appointments, manage the list of services, and respond to enquiries.

Key Implementation Details:
  • Database connectivity and configuration handled via a central config.php file.
  • Dynamic service list and appointment time slots generated using PHP loops.
  • Appointment form enforces clinic timings (10:00–13:00, 14:00–20:00) and prevents Sunday bookings.
  • Each time slot is limited to three appointments by checking the appointments table.
  • Contact form uses prepared statements to avoid SQL injection vulnerabilities.

Testing

Different levels of testing were performed to ensure the correctness and reliability of the system.

Unit Testing

  • Validation of appointment date (past date and Sunday restriction).
  • Slot availability logic (maximum three bookings per slot).
  • Form validation for required fields in appointment and contact forms.

Integration Testing

  • Interaction between appointment.php and the appointments table.
  • Integration of services.php with the services table for list and detail view.
  • Admin update of appointments via admin/edit_appointment.php reflected correctly on the public side.

User Interface Testing

  • Responsive layout on desktop and mobile resolutions.
  • Navigation between Home, About, Services, Appointment and Contact pages.
  • Display of success and error messages in a user-friendly manner.

Conclusion

The Physio Care Center project successfully demonstrates the design and implementation of a web-based appointment and service management system for a physiotherapy clinic. By automating appointment booking, enforcing time-slot rules and providing an admin panel for clinic staff, the system reduces manual effort and minimizes scheduling errors. The project also showcases practical usage of PHP, MySQL, HTML and CSS in a real-world healthcare context.

Overall, the system meets the defined objectives and can be deployed with minor configuration changes for use by small and medium physiotherapy centers.
